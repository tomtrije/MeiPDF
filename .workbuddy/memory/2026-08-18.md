## 续做：DMG + Sparkle + 推 GitHub（同日后续）
- 新增 `Updater.swift`（SPUStandardUpdaterController）+ "检查更新…" 菜单；Info.plist 加 `SUFeedURL`/`SUPublicEDKey`/`SUEnableAutomaticChecks`。
- `build-app.sh` 嵌入 Sparkle.framework（macOS slice）到 `Contents/Frameworks/`，并 `install_name_tool -add_rpath "@executable_path/../Frameworks"`（SwiftPM 二进制只有 `@loader_path`，不嵌框架会 dyld 崩溃），再 `codesign --deep`。
- `build-dmg.sh`：hdiutil 打 `MeiPDF-x.y.z.dmg`（含 .app + Applications 软链）。
- `release.sh`：build-dmg → `gh release create` 上传 DMG → `generate_appcast --download-url-prefix`（Sparkle 工具在 `.build/artifacts/sparkle/Sparkle/bin/`）→ 输出 `appcast.xml` 到仓库根。
- **Ed25519 密钥坑**：`generate_appcast --ed-key-file` 要「32 字节 seed 的 base64」而非 PEM；macOS `base64` 用 `-b 0`（无 GNU `-A`）。`SUPublicEDKey` 必须与新 seed 对应，否则 appcast 不签名。密钥 `sparkle/ed25519_private.{pem,key}` 均 gitignore。
- `swift package resolve` 拉取 Sparkle 2.9.6（XCFramework 二进制）。
